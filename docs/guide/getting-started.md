# Getting started with Minimal

New to Minimal? Like everyday usage, getting started with Minimal is simple. This documentation will walk you through how to install Minimal, how to initialize projects, and how to define your toolchain and dependencies for use across the org.

Minimal is a secure, declarative runtime for Claude Code, Gemini, Codex, Pi, and more: run multiple agents safely on your stack, from a verified software supply chain. All builds and dev environments run entirely on your machine within isolated sandboxes. Minimal creates a consistent foundation for all users, whether developer, AI agent, or CI, around the org's tech stack.

Minimal is available for download on both Linux and macOS. [Learn more.](https://minimal.dev)
